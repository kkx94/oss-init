# Security Policy

## Supported Versions

Only the latest released version of oss-init is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you discover a security issue, **please do NOT open a public issue**. Report it privately to the maintainers via a [security advisory](https://github.com/kkx94/oss-init/security/advisories/new) or the maintainer email listed on the repository profile.

Please include in your report:

1. The affected version(s)
2. A description of the vulnerability and its impact
3. Steps to reproduce the issue
4. Any suggested fix, if you have one

### What happens next

- We acknowledge your report within 5 business days
- You receive a status update when the issue is triaged
- We coordinate a fix and a coordinated disclosure timeline with you
- We credit you in the security advisory when the fix is released (unless you prefer to stay anonymous)
